バトルBGM：複数曲からランダム再生

1. 好きな音源をこのフォルダへ入れます。
   例：battle-1.mp3、battle-2.mp3、battle-3.mp3
2. tracks.jsonのtracks配列に、実際のファイル名を登録します。
   同じフォルダ内のMP3 / M4A / OGG / WAVに対応します。
   例：{"tracks":["battle-1.mp3","my-song.m4a","boss.wav"]}
   曲数の上限はありません。拡張子だけを変えても形式は変換されません。
3. 音源とtracks.jsonを含め、サイトをアップロードし直します。
4. ページを再読み込みし、画面をタップしてから対戦を開始します。

CPU戦・友達との対戦ともに、開始ごとにランダムで1曲を選びます。
同じ曲が続けて選ばれることもあります。
1回のバトル中はその曲だけがループし、バトル終了・退出時に停止します。
ミュートや別タブから復帰しても、そのバトルでは同じ曲を再生します。
端末が対応しない形式・未配置・壊れた音源は飛ばして別の曲を試します。
大きな音源は読み込みに時間がかかるため、圧縮したMP3を推奨します。
登録曲を再生できないときは従来のbattle.mp3 / m4a / ogg / wavを順に試します。
音源がなくてもゲームと技の効果音は動作します。
BGMと効果音の音量・ミュートはサウンド設定で調整できます。
実際の音源は同梱していません。自分たちの音源を配置してください。

ダウンロード版ではpublic/assets/audio/がこのフォルダです。
公開中のサイトは、手元のフォルダへ入れただけでは更新されません。


ロビーBGMの入れ方
このフォルダへ lobby.mp3 を配置して、音源も含めて公開し直してください。
MP3のほか lobby.m4a / lobby.ogg / lobby.wav も使えます。
複数形式があるときは上記の順で、端末が再生できる最初の音源を使います。
ロビーはtracks.jsonへの登録不要です。曲名をlobbyにしてください。
画面を最初にタップするとロビー曲をループ再生します。
相棒・QR入手・図鑑などを移動しても同じロビー曲が続きます。
対戦開始時にロビー曲を止め、ランダムなバトル曲へ切り替えます。
結果画面では指定した勝敗BGMを再生し、ロビーへ戻るとロビー曲を再開します。
別タブやミュート中は停止し、復帰時に再生を再開します。
ロビー曲は未同梱です。手元に入れるだけでは公開サイトに反映されません。


勝利・敗北・引き分けBGMの入れ方
このフォルダへ次の名前で音源を配置します（tracks.jsonへの登録不要）。
勝利：victory.mp3
敗北：defeat.mp3
引き分け：draw.mp3（任意）

各曲とも同名の .m4a / .ogg / .wav も対応します。
複数形式がある場合は mp3 → m4a → ogg → wav の順で、再生可能な音源を使います。
拡張子だけ変更しても音声形式は変換されません。

CPU戦・友達との対戦の両方で、自分の勝敗に合う曲を再生します。
最後の技のアニメーションが終わり、結果画面が出た時点でバトルBGMから切り替わります。
結果画面を開いている間はループし、部屋を離れると停止します。
ロビーへ戻るとロビー曲、新しい対戦ではランダムなバトル曲に切り替わります。
該当する勝敗曲がなければ結果画面は無音です。合成ジングルは追加していません。
BGM音量・ミュート設定は勝敗BGMにも共通で適用されます。
別タブ中は停止し、結果画面に戻ると再開します。

音源は同梱していません。音源を入れたらフォルダごとサイトへ公開し直して、
ページを再読み込みしてください。手元に置くだけで公開中のサイトは変わりません。

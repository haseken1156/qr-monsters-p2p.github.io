# 利用者向け公開フォルダ

このpublicフォルダの中身だけをGitHub Pagesにアップロードします。
QR一覧、直接受け取り、手入力を削除しました。モンスター・素材の入手には開発者の電子署名付きQRが必要です。
署名確認用の公開鍵だけを同梱し、発行用の秘密鍵やQR一覧・画像は含みません。
育成・5タイプ・20体・4択の技・P2P対戦はそのままです。
旧版で配った署名なしのQRは使えません。developer-privateのツールで再発行してください。
同じ公開元なら入手済みの育成データを引き継ぎます。同じモンスターは1体までです。
QRは各プレイヤーが1回使用できます。コピー・転送された正規QRを別の利用者が使うことは制限できません。
端末保存とP2P方式のため、保存データの書き換えや改造版クライアントを使う不正までは防げません。厳密な個人別配布・全員合計1回の利用制限には認証付きサーバーが必要です。
実機同士のP2P接続とカメラ読み取りは未確認です。

## パソコンでの動作確認

- パソコン、スマホ、タブレットすべてでゲーム画面を表示します。端末判定による制限を廃止しました。
- パソコンではマウスで各画面のボタンを操作できます。
- カメラがない場合は「QR入手」→「QR画像を選ぶ」で、開発者から受け取ったQRのPNGやスクリーンショットを読み込みます。
- 公開されたHTTPSのURLをChromeまたはEdgeで開いてください。QRの署名確認やP2P対戦はブラウザの対応・回線に依存します。
- index.htmlをダブルクリックして開くと、ブラウザの制限でJavaScriptが読み込まれない場合があります。公開URLで確認してください。
- 同じ公開元・同じブラウザであれば、これまでの育成データと新しい署名付きQRをそのまま使えます。管理パスワードと発行用の鍵は変更していません。
- Windowsのユーザーエージェント・タッチ操作なしの条件で画面表示、メニュー切替、QR画像選択、カメラなしの案内、署名付きQRからの入手・育成を確認しました。実機同士のP2P接続は未確認です。
